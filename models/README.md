# Model Artifacts

This directory will eventually contain exported model artifacts and their associated metadata. No model artifacts exist during Phase 0.

Each future artifact should be traceable through metadata that includes, where relevant:

- model or module name
- version
- training timestamp
- dataset and dataset version
- feature schema
- validation strategy
- evaluation metrics
- decision threshold, if relevant
- library versions

Generated artifacts are excluded from version control; this README preserves the directory guidance.
